# 3_section_labels

What kind of text each brought-in piece of each book is: **rule**, **flag**, **reference** or **not_for_checking**, with a topic, a reason and one short exact quote (page, lines), as for New York (`regulations/document_extraction_guide/labeling_guide.md`).

- `icc.ibc.2009.yaml`, all 154 pieces: rule 16, flag 13, reference 119 (definitions and pointers to them), not_for_checking 6 (section headings). A label says what the text is: 1016.1 is a rule (a measurable limit), though its drafted rule is a flag because the copy is OCR only. Each IBC label's notes say "Read from an OCR copy only: not verified" and name the OCR's meaning-changing misreads its piece holds ("1-4" for Group I-4, "I-hour" for 1-hour), with the book's ICC reading; the copy's page image prints the OCR's reading, so it can't confirm them.
- `gov.law.nfpa.101.2012.yaml`, all 143 pieces: rule 20, flag 14, reference 81 (Chapter 3 definitions and pointers, how to measure), not_for_checking 28 (headings, the term-group headings of Chapter 3 that define nothing themselves, and the exiting-diagram submittal of 16.1.7.2 and 17.1.7.2). Flags are permissions that turn on sections not brought in (doors per 7.2.1, locking per 7.2.1.6) and hardware a person judges.
- Drafted by hand in a Claude Code session (2026-11-20), not by the labeling script, so there is no run record; every label stays a draft (approval is deferred).
- `python -m rule_format` checks every label against the pieces; where the code cache has the books, every quote word for word. A quote that repeats on its page counts when its own piece holds it exactly once (the IBC's one-line "LOADS. See Section 1602.1." is also the end of "LIVE LOADS. See Section 1602.1.").
- `<book>.review.md` (generated by `python -m section_labeling coverage` where the cache exists; never hand-edit) lists the labels to look at first.
