# 4_term_definitions

How the 2009 IBC and NFPA 101 (2012) define the words the commercial egress rules depend on (story, building area, means of egress, exit, exit access, exit access doorway, common path, corridor, occupant load, automatic sprinkler system, fire partition, fire-resistance rating, existing, day-care home, smoke partition, separated occupancy, panic and fire exit hardware...). `definitions.yaml`: each term with its book's own whole definition, quoted exactly with page and lines, no paraphrase, keyed `ibc_` or `nfpa_`: a rule of one book reads its own book's definition, and where the two books define the same word (story, exit, occupant load, common path) both are kept.

**How each book's definitions apply.** The IBC prints its defined words in italics (its preface: "Selected terms set forth in Chapter 2, Definitions, are italicized where they appear in code text"; 201.1), so a word applies with its Chapter 2 meaning where it is italicized. **NFPA 101 marks no defined word**: by 3.1 ("The definitions contained in this chapter shall apply to the terms used in this Code"), every Chapter 3 term applies wherever the Code uses it, italics or not, and a term it doesn't define takes its ordinary meaning (Merriam-Webster's Collegiate Dictionary, 11th edition). The IBC's quotes are read from an OCR copy only: not verified.

`python -m rule_format` checks every quote where the code cache has the books. The measures that use these words are defined in `packages/rule_format/rule_format/parts.yaml` (story, space, corridor, means-of-egress door) and the folder's proposed measures.
