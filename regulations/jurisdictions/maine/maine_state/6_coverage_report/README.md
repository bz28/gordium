# 6_coverage_report

Proof that nothing in the brought-in parts of either book was skipped (`<book>.md`): every line of every page read is in exactly one piece, or is page furniture (the stamped number, the running head, the footer, NFPA's licence stamp), or belongs to a part of the book that is not brought in (each named in the sections file). Then each piece with its label.

`<book>.rules.yaml` lists every piece labeled rule or flag with the rules written for it, and `not_checked_yet`, the ones with none (empty for both books). A rule counts for a piece when its id names the piece (Maine's ids name the book first: `general.ibc_1016_1_...`, `general.nfpa_16_2_6_2_...`) and one of its sources quotes the piece; a rule written for a section counts for each table it quotes too (Table 1016.1 for 1016.1). A check would read it and name any piece left as "Not checked yet by Gordium", so this law never reads as complying while any is left.

**Generated by code only** (`python -m section_labeling coverage`). **Never hand-edit.** It counts lines from the sections file's line counts, so CI checks it even without the books.
