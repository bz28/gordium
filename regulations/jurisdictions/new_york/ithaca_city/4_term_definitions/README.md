# 4_term_definitions

How the City of Ithaca defines the words its rules depend on: height, story, grade plane, lot coverage, yards, etc. (mostly from §325-3).

These say *what* a term means, with the source quote. The code that *measures* it in a Rhino model is written by engineers in `packages/model_measurement` (later). Architects would confirm each definition, but that is deferred for now (like rule approval), so they answer the open questions instead.
