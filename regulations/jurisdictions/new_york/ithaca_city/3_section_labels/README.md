# 3_section_labels

Every clause of every source document gets two labels:

- **kind** — what the system does with it: **Rule** (checked automatically), **Flag** (shown to the architect to judge), **Reference** (points elsewhere), **Not for checking** (e.g. procedures).
- **topic** — how architects think about it. Starting list (to follow Chapter 325's own table of contents; architect confirmation is deferred for now): districts and map; uses; dimensions; density and occupancy; parking and loading; overlays; form and design standards; site features; nonconforming lots and buildings; procedures; definitions; administration.

Most labels come from *where* the text sits in the document; AI drafts the rest; code checks them (architect confirmation is deferred for now). One file per source document.
