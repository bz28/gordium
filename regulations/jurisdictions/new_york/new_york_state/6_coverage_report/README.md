# 6_coverage_report

Proof that nothing in the brought-in parts of the book was skipped (`<book>.md`): every line of every page read is in exactly one piece, or is page furniture (the stamped number, the running head, the footer), or belongs to a part of the book that is not brought in (each named in the sections file: the end of R317 above R318, the definitions no brought-in section uses...). Then each piece with its label.

For this state law, `<book>.rules.yaml` also lists every piece labeled rule or flag with the rules written for it in the rulebook a check uses, and `not_checked_yet`, the ones with none. A check reads it and names those sections as "Not checked yet by Gordium" (one needs-review line), so egress never reads as complying while any is left; their plain names are `../section_names.yaml`.

**Generated by code only** (`python -m section_labeling coverage`). **Never hand-edit.** It counts lines from the sections file's line counts, so CI checks it even without the book.
