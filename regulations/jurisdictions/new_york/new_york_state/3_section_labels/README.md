# 3_section_labels

What kind of text each brought-in piece of the 2025 Residential Code of New York State is: **rule**, **flag**, **reference** or **not_for_checking**, with a topic, a reason and a short exact quote (page, lines), as for Ithaca (`regulations/document_extraction_guide/labeling_guide.md`).

- All 169 pieces are labeled: rule 53, flag 10, reference 99 (definitions, pointers, how to measure), not_for_checking 7 (section headings, and the lodging-house notice of R318.1.1). Drafted by hand in a Claude Code session (2026-11-12), not by the labeling script, so there is no run record; every label stays a draft (approval is deferred).
- `python -m rule_format` checks every label against the pieces; where the code cache has the book, every quote word for word.
- `<book>.review.md` (generated by `python -m section_labeling coverage` where the cache exists; never hand-edit) lists the labels to look at first.
