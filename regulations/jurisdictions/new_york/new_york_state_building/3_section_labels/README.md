# 3_section_labels

What kind of text each brought-in piece of the 2025 Building Code of New York State is: **rule**, **flag**, **reference** or **not_for_checking**, with a topic, a reason and one short exact quote (page, lines), as for the house code (`regulations/document_extraction_guide/labeling_guide.md`).

- `gov.ny.building.2025.yaml`, all 150 pieces: rule 10, flag 15, reference 123 (definitions, how to measure, pointers), not_for_checking 2 (section headings).
- Drafted by hand in a Claude Code session (2026-11-21), not by the labeling script, so there is no run record; every label stays a draft (approval is deferred).
- `python -m rule_format` checks every label against the pieces; where the code cache has the book, every quote word for word.
- `gov.ny.building.2025.review.md` (generated by `python -m section_labeling coverage` where the cache exists; never hand-edit) lists the labels to look at first.
