# New York's house code: where its text lives, and how a place inherits it (2026-11-12)

**Purpose:** why the 2025 Residential Code of New York State is kept outside the repo, how its text is still checked, and how Ithaca inherits a state law folder.\
**For:** engineers adding a building code, and Ben (copyright and the copy we read).\
**Kept current by:** the engineer who brings in another state code book or changes the code cache, in that PR.

Egress (the ways out of a house: doors, stairs, landings, handrails, guards, escape windows) is set by New York's building code for houses, not by Ithaca's zoning. That code is the **2025 Residential Code of New York State** (RCNYS), published by the International Code Council (ICC). Three questions had to be settled before any egress rule could be written: which edition is law, where its copyrighted text may live, and how a city folder picks up a state's law.

## Decisions

1. **The edition is the 2025 RCNYS.** It is law for one- and two-family houses and townhouses not more than three stories above grade plane since 2025-12-31 (19 NYCRR §1220.2(a), §1219.2(a)(8), in the Department of State's rule text of 2025-12-02); the choice of the 2020 code ended with the transition on 2025-12-30. Sources, with links, are in `regulations/jurisdictions/new_york/new_york_state/1_source_documents/sources.yaml`.
2. **The copy we read** is the one Public.Resource.Org posted on the Internet Archive (item `gov.ny.residential.2025`, 2026-02-02), chosen by Ben (option D) as a working copy. It turned out to be ICC's own PDF edition, with real text in its fonts (not a scan, so no OCR), and a nine-digit number stamped on every page. ICC's online viewer may not be read by a script or an automated browser (its terms forbid automated extraction and commercial use), so it is never used. Everything is marked **verified against this copy only; check against an exact copy bought from ICC** until Ben buys ICC's PDF.
3. **Only short exact quotes go in the repo**, each with its section, page and a link. The book, its full extracted text and any page images stay in a **code cache outside the repo**, one folder per fingerprint: `<cache>/<sha256>/gov.ny.residential.2025.pdf` and `.../gov.ny.residential.2025.jsonl`. The cache is `$GORDIUM_CODE_CACHE`, else `~/Documents/gordium_archive/code_cache` (not `/tmp`: macOS deletes files there after three idle days). `sources.yaml` marks the book `kept_outside_repo: true` and records its link, fingerprint, terms and what kind of copy it is.
4. **What the repo keeps of the book** is only what has no copyrighted wording beyond section titles and short quotes: the sections file (`2_extracted_text/<book>.sections.jsonl`: each piece's section number, title, line ranges, a fingerprint of its words, and the definitions it uses), the labels and definitions (with short quotes), the second reading of its numbers, and the coverage report.
5. **Where the cache exists, every check runs as for Ithaca**: the text is re-extracted and must match the cache byte for byte; every quote is checked word for word; the sections are re-cut and must match the repo's; the recorded numbers must be the text's. **Where it doesn't (CI)**, those checks are skipped and each run says how many it skipped and why ("199 quotes ... not checked here", the number of quotes of the book). Nothing is passed in their stead, and the checks that need no text still run: the labels against the pieces, the coverage count from the line counts, the state settings.
6. **A state law folder** sits beside the places: `regulations/jurisdictions/new_york/new_york_state/`, with the same numbered steps, but with a `state.yaml` instead of a `jurisdiction.yaml`. It is no place (no boundary, no address lookup), so the place registry and the Rhino plugin, which checks exactly one place, never see it. A place lists the state folders whose law applies to it: Ithaca's `jurisdiction.yaml` says `inherits: [new_york/new_york_state]`. The registry refuses an `inherits` that names no state folder, or another state's, and a place that names none when its state has a state law folder (a place that silently inherited nothing would be checked against too little law). In this step the link is only declared and checked: nothing reads the state's law into a place's check until egress rules exist; that step adds a test that Ithaca's check includes them.
7. **Every number is read twice.** A misread limit (8 1/4 read as 8) could pass a stair that fails. Each brought-in piece is cropped from the page image, and a helper that never saw the extracted text reads every number, with the words before and after it. What is compared for each number is its value, its unit ("square feet", "units horizontal"), the comparison words directly before it ("not more than") and any directly after its unit ("or more"); comparison words further back ("not exceeding a total floor area of 200 square feet") are not, and are left to the word-for-word check of each rule's quote. Both readings go through the same code (`document_extraction/numbers.py`) and are compared item by item. Both lists are recorded per piece in `new_york_state/text_verification.yaml`; code compares them on every run (so "agrees" is code's verdict, never a word taken on trust) and checks them against the pieces (and, where the cache exists, against the text). A number is digits, a fraction, a number word, or a part of a whole ("a quarter circle", "one-half").

## How it works

- **Extraction** (`document_extraction/icc.py`): ICC prints a fraction stacked (a small raised 1, a slash, a small lowered 4). Read line by line, the 4 falls onto a line of its own and the 1 looks like a footnote marker, so the extractor puts each stacked fraction back on its line ("8 1/4", with a space so it can never read as 81/4). It also records which words are italic and bold.
- **Cutting** (`document_extraction/icc_sections.py`): a piece starts at a line that starts in bold: a section heading, a numbered part ("R318.7.5.1 Risers."), or a defined term in Section R202. A numbered part out of order is reported, never skipped; so is a brought-in part that is the last before a page not read (it may run on there), which is why the pages read include the next part's heading after each brought-in section. A chapter's opening (its title and ICC's user notes) ends the part before it and is no law.
- **Which definitions come in is decided by the law, not by hand.** R201.1 says the words printed in italics have the meanings in Chapter 2, so code reads the italics in the brought-in sections, brings in each definition they name, then the definitions those definitions use. Definitions whose term a section prints in roman type come in too (never fewer), with the definitions they use. A brought-in piece that uses a definition not brought in is a problem.

### Worked example

[NY] R318.7.5.1 (risers) is on page 100. The extractor reads its first line as "... shall be not more than 8 1/4 inches (209 mm)". The cutter starts a piece at the bold "[NY] R318.7.5.1 Risers." and ends it at the bold "[NY] R318.7.5.2 Treads.". Its italic words (riser, flight, nosing, grade, spiral stairways) bring in those definitions (both riser definitions, RISER (STAIR) and the plumbing one, since the book defines the word twice), and "stairway", printed in roman there, comes in by the roman-type match. Code lists its numbers ("not more than 8 1/4 inch", "209 mm", "by more than 3/8 inch", ...). A helper looking only at the cropped page image lists the same numbers, so `text_verification.yaml` says `R318.7.5.1: second_reading: agrees`. The label file quotes "[NY] R318.7.5.1 Risers. The riser height shall be not more than 8 1/4 inches (209 mm)." on page 100, line 42; on Ben's Mac `python -m rule_format` checks those words are there; in CI it says the quote was not checked.

## Alternatives rejected

- **Commit the book or its text.** Copyright: the full text may not be redistributed.
- **Read ICC's online viewer.** Its terms forbid automated extraction and commercial use.
- **Make the state folder a place** (a `jurisdiction.yaml` with no boundary). It would be a second place, and the Rhino plugin refuses to start when there is more than one place.
- **Put the state's law inside Ithaca's folder.** Every New York place would need its own copy, and they could drift apart.
- **Pick the definitions by hand.** A missed definition is a missed meaning; the book's italics say which ones apply.
