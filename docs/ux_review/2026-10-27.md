# UX review, 2026-10-27: the demo, walked through as an architect

**What was tested:** the demo build (`demo` at 39107691 plus the fix below) in Rhino 8 on a Mac laptop
(1470 x 956 points). I started from a new, empty file in millimetres and used real mouse clicks and key presses
in Gordium's own windows. The one exception was moving the house: Rhino's command line would not take a typed
`Move` from the automation, so that move was made by a script (see *Not covered*).

**The flow:** empty file → address with suggestions → start box → Use and questions → Draw → edit the house →
Check → select a row (highlight and details) → Zoning report → Undo / Redo → Edit site… and a new lookup → Esc.

Screenshots are in [2026-10-27/](2026-10-27/), downscaled, with the personal notification cropped out.

## Score for each step (1 = blocks the architect, 5 = feels like Rhino)

| Step | Score | What an architect sees |
|---|---|---|
| Start in an empty file | 3 | "Starting Gordium's checker…" for about 14 s the first time. After that the box opens already filled in with the sample project. |
| Address with suggestions | 4 | Typing "204 Utica" offers "204 Utica St, Ithaca, NY". Down then Enter picks it, and Enter looks it up. The live status line counts the seconds and says where it stops. |
| Start box | 3 | The district is correct ("R-2b, suggested by Gordium · City zoning map says R-2b"). Draw stays off until "This is the lot's district" is ticked, which is a good safeguard. But the Lot and Front lot line rows still show the sample project's values (01). |
| Use and questions | 3 | Seven household and home-occupation questions are shown before anything is drawn. Item 14 (facts up front) is already working on this. |
| Draw | 4 | "Finding the largest building that complies…" shows a timer, Cancel and Esc, and takes about 20 s. The result is one named Undo step (03). |
| Edit, then Check | **2 → 4** | Before the fix, every press of Check left the panel saying "Model changed since the last check" (04). After the fix it checks in 1.2 s and the results stay current (05). |
| Select a row | 4 | The row shows the city's words, the formula with the numbers filled in, what was measured and the citation (06). "Zoom to" is greyed out for a row with no offending part, and nothing says why. |
| Zoning report | 4 | It is saved next to the file (for an untitled file, in ~/Documents) and opens. On this Mac, Excel is unlicensed and shows a subscription page. That is the Mac's setup, not Gordium. |
| Undo / Redo | 4 | Cmd+Z undoes "Gordium: start fresh for 204 Utica Street…" as one step, and Cmd+Shift+Z brings it back. |
| Edit site…, a new lookup, Esc | 4 | An address that is not found gets a clear sentence, and the lot is kept (07). Esc closes the box. |

Millimetre files work: Rhino shows coordinates in mm, and Gordium reports feet and inches.

## Problems, worst first

1. **Fixed: Check greyed out its own results (P0).** After Draw, every check deleted and redrew Gordium's locked
   snap curves, and live mode counted that as an edit of the model. So the panel always said "Model changed since
   the last check — press Check". The fault is in #34 (`_envelope_curves`). It only showed up in the demo, because
   #32's check records the moment the model was read. The fix: replacing the curves leaves the "model changed" mark
   exactly as it was. It is in #34 d5ae80b, then carried into #35 cd0db96, #37 1ac5b1a and demo 3875ca3.
   - Tests that pin it: `test_dimensions` (fails when the fix is reverted) and the in-Rhino claim 3b in
     `osnap_in_rhino.py` (11 of 11 pass; 10 of 11 when reverted).
   - One cold review round: no confirmed findings.
2. **For Ben: the start box shows the sample's lot after a lookup (P1, 01).** In an empty file, after looking up
   204 Utica St, the box still says "Lot 7,033 sf · from the tax map" and "Front lot line: Ithaca Rd". Those are
   106 Ithaca Rd's values. After Draw it correctly shows 3,493 sf and Utica Street. This follows the rule "Look up
   only fills the box; the rows keep saying what is drawn". But in an empty file nothing is drawn, so the rows
   describe neither the drawing nor what Draw will make. One option: show the looked-up values, marked "after Draw".
3. **For Ben: on narrow lots the "largest house" is very narrow (P1).** On a 35 ft lot in R-2b, which needs one
   side yard of 10 ft and the other of 5 ft, the starting house keeps 10 ft on *both* sides. The note says
   "limited by the yards (… sides 10'-0" …)". The result is about 9 ft wide, with a 525 sf footprint. This is how
   the envelope was designed: every lot line is pushed in by the largest yard it could need, so it can never give a
   false pass. But an architect reads "largest house that complies" literally. One option: for the starting house
   only, put the 10 ft yard on one chosen side.
4. **Wording (P2).**
   - The sample prefill says "R-1b · entered by you", and the site facts say "Use: … the sample project ·
     confirmed by you". The architect entered neither.
   - "Eaves into front yard 13'-0"" reads as eaves that stick out 13 ft. It is actually the distance from the eaves
     to the front lot line. "Front yard at the eaves" would say that.
5. **Suggestions go silent when nothing matches (P2, #32/#33).** For "312 Hudson St" the service returns no
   suggestions, so no list and no note appear. A quiet "No matching address: press Look up" would tell the
   architect the feature is working.
6. **Questions up front (P2).** Covered by item 14.

## Speed (measured in Rhino)

| Action | Time |
|---|---|
| First start of the checker | about 14 s |
| Draw (largest building) | about 20 s, with progress and Cancel |
| Check | 1.2 s per press (3 runs: 1.21, 1.26, 1.24 s) |

**How a check's 1.2 s splits:** 1.1 s is the checker's own work. Reading the model and drawing the results in Rhino
takes under 0.1 s.

**The rulebook cache was not built.** Each check parses 20 rulebook YAML files (17 different ones). A cache keyed
on each file's fingerprint would save about 0.24 s per check in a test run (0.56 s down to 0.32 s). That is about
a fifth of a 1.2 s Check. I judged that not slow enough to justify another PR now. It is a small PR off main if
wanted.
