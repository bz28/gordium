# IFC building models

Real building models in IFC (the open file format design tools export), read by
[`packages/ifc_reading`](../../packages/ifc_reading/README.md) into Gordium's interior description. One folder per
model: the original file, unchanged and under its own name; `<model>_interior.yaml`, the description the reader
makes from it (generated by code, never hand-edited; `python -m ifc_reading --check` proves it is current); a
README with where the file came from and its licence.

| Model | What it is |
|---|---|
| [`ac20_fzk_haus`](ac20_fzk_haus/README.md) | KIT's FZK-Haus: a two-storey house, ArchiCAD 20, IFC4, metres, German room names |
