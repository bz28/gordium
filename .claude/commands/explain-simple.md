Explain what you just did in the simplest English possible, as a **short bulleted list**, for an architect or shareholder who has never coded.

- 4–8 bullets, one idea each. Lead with **why** it was needed, then what was done.
- No jargon; if a technical word is unavoidable, explain it in parentheses.
- Use building and zoning analogies (a rule file is like a marked-up code book; a fingerprint is like a notary seal on a document).
- Group by feature, not by file.
- Say plainly what is **verified** and what still **needs an architect** (approvals, unclear interpretations).
- End with **Bottom line:** one sentence.
- Then **Try it:** the exact 2–3 steps to check it locally, and what you should see.
